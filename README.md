# MATH261A-Project1-Diabetes

Project 1 repository for MATH 261A.

## Data
The data used in this project were obtained from California Open Data. Diabetes hospitalization data were provided by the California Department of Health Care Access and Information, while county income data were provided by the California Franchise Tax Board. The analysis uses 2022 county-level data for 58 California counties.

The original datasets can be downloaded from the following sources:

[Rates of Preventable Hospitalizations for Selected Medical Conditions by County](https://data.ca.gov/dataset/rates-of-preventable-hospitalizations-for-selected-medical-conditions-by-county-lghc-indicator)

[B-6, Comparison By County](https://data.ca.gov/dataset/b-6-comparison-by-county2)
